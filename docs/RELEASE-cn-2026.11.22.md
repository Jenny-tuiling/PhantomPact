# 小朋友快乐玩mod：《影之刃零》本地 2–4 人合作（2026.11.22 跨机器测试版）

适用于《**影之刃零**》（**Phantom Blade Zero**，S-GAME）Windows / Steam 版的**同一台电脑本地 2–4 人**合作扩展包。
**这是同一台电脑多屏多人，不是各人一台电脑联网联机。**

- 游戏：《影之刃零》Steam 版，验证版本 build **26367565**（不匹配时安装器会停止，请勿绕过）
- 基础版本：粉丝模组 Phantom Pact **v1.7.3** — https://github.com/yhsharaf/PhantomPact
- 本分支：`cn/four-player-local`，= v1.7.3 + 1 个提交 —
  [对比](https://github.com/Jenny-tuiling/PhantomPact/compare/v1.7.3...cn/four-player-local)
- 版本号：`2026.11.22-test`
- 压缩包：`PBZ-KidsCoop-4P-2026.11.22-test.zip`（约 20 MB，解压后约 69 MB）

## 安装

1. 先正常安装并用 Steam 启动过一次游戏，确认 build 26367565。
2. 保存并退出游戏，关掉所有设备设置页。
3. 把 ZIP **完整解压**到普通文件夹（不要在压缩包里直接运行）。
4. 双击 `Install.cmd`，选择游戏根目录（含 `platform` 与 `ProjectPBZ` 的那一层，可在 Steam→属性→已安装文件→浏览 找到）。
5. 等“安装完成”。安装器会备份原文件，并在桌面创建“小朋友快乐玩mod - 多人设备设置”快捷方式。
6. 从桌面快捷方式打开设置：默认单人，勾选开启多人，选 2/3/4 人及输入组合；显示器先在 Windows 设为扩展显示。
7. 各玩家依次按自己手柄 A 加入；摇杆偏移点卡片顶部“归中校准”，松开两摇杆约 4 秒。
8. 选皮肤 → 设备检查 → 启动。游戏正常从 Steam 启动，进自己的存档。

**卸载**：退出游戏与设置页，双击 `Uninstall.cmd` 选同一游戏根目录。备份在游戏根目录 `FourPlayerBackups`，请保留该解压目录直到卸载完成。

## 与上游 v1.7.3 的差异

- 2/3/4 人本地合作，2/3/4 号玩家独立输入路由
- 手柄绑定与摇杆归中校准，设备归属保持
- AI 托管（队友 L3+RT 按住 4 秒开关，重启后保持），2/3/4 号独立开关
- 复活点修正、召回全部队友（1号 R3+LT）、安全脱困（L3+R3）、锁定队友操作（1号 L3+RT）
- 皮肤：原始魂、辰辰、小宝、猪八戒、枫枫（不含帝皇、叶瞬光、Seed）
- 设置页重写（C# WinForms）＋底座切换：本地测试版 / 稳定版 1.7.3＋现有补丁
- 游戏工具：全员无敌＋10 倍伤害（每次启动默认关闭）

## 已知问题

- 穿行地图在多人下仍有光标/选点问题，未宣称修复。
- 庞镇切图尚未实测通过；同时喝药归属、缺席路由、安全复活落点仍有风险。
- 猪八戒、枫枫资源与构建已检查，游戏内全部动作与场景尚未验收。
- AI 在制作机实测通过，新机器/其他游戏版本需自行验证。
- 本包不含作者存档、手柄绑定与校准数据，请用自己电脑的备份存档。

## 兼容与注意事项

- 与其它版本的多人模组**不要混装**；已装旧版请先按原包方式卸载。
- 不要删除自己的游戏存档；安装前建议备份 `ProjectPBZ/Saved/SaveGames`。
- 安装器/卸载器发现文件被改动会停止并提示路径，属保护行为，按提示处理，不要强删备份。
